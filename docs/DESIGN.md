# 물비늘 섬 (Mulbineul Island) — 게임 기획서

멀티플레이 3D 로우폴리 낚시 웹게임. 브라우저로 접속하면 모두가 하나의 섬에서 함께 낚시합니다.

## 1. 핵심 루프

```
채집/구매/손질 → 미끼 제작 → 지역·시간·날씨에 맞춰 캐스팅 → 입질 → 챔질 → 추적 바 미니게임
   ↑                                                                     ↓
낚싯대 업그레이드 ← 판매(돈) ← 물고기(종·무게·품질·변이) → 도감/랭킹/파티 버프
```

## 2. 확정된 결정 사항

| 항목 | 결정 |
|---|---|
| 기술 스택 | Node.js + `ws` 서버, Three.js + Vite 클라이언트, 공용 데이터/지형 모듈(`shared/`) |
| 멀티 방식 | 공유 월드 (실시간 이동·캐스팅 표시, 채팅, 대어 알림, 랭킹) |
| 저장 | 서버 저장 (닉네임 + 브라우저 토큰, JSON DB) |
| 그래픽 | 외부 에셋 없이 코드로 만든 로우폴리 카툰 |
| UI | 나무 판자 + 크림색 종이 테마, 직접 그린 SVG 아이콘 (이모지 없음), 제목 Jua · 본문 Gowun Dodum |
| 재료 획득 | 맵 채집 + 물고기 손질 + 상점 구매 + 플레이어 간 거래 |
| 변이 효과 | 외형 이펙트 + 가치 배수 + 일부는 주변 플레이어 파티 버프 |
| 맵 | 섬 하나에 6개 지역 |

## 3. 월드

### 지역 (6)
| 지역 | 위치 | 필요 낚싯대 | 분위기 |
|---|---|---|---|
| 잔잔한 호수 | 섬 북쪽 | 1단계 | 맑은 민물 |
| 굽이치는 강 | 호수 → 동쪽 바다 | 1단계 | 급류, 바위 |
| 모래 해안 | 남쪽 해변 | 1단계 | 얕은 바다 |
| 안개 늪 | 서쪽 저지대 | 2단계 | 탁한 물, 버섯, 반딧불 |
| 심해 (부두 끝) | 남동쪽 긴 부두 | 3단계 | 깊고 어두운 바다 |
| 화산 온천 | 북서쪽 산 분화구 (동남쪽 협곡으로 진입) | 4단계 | 김, 유황, 주황빛 물 |

### 시간과 날씨
- 하루 = 실제 24분 (게임 1시간 = 실제 1분). 시간대: 새벽(5–7시), 낮(7–17시), 저녁(17–19시), 밤(19–5시)
- 날씨: 맑음, 흐림, 비, 안개, 폭풍. 4–9분마다 서버가 바꿈
- 일부 물고기는 특정 시간대나 날씨에만 나오고, 일부 변이는 특정 조건에서 확률이 오름

## 4. 물고기

### 희귀도 (6단계)
| 희귀도 | 색 | 기본 출현 가중치 | 기본가 범위 |
|---|---|---|---|
| 일반 | 회색 | 600 | 8–30 |
| 고급 | 초록 | 250 | 40–90 |
| 희귀 | 파랑 | 100 | 120–300 |
| 영웅 | 보라 | 22 | 400–900 |
| 전설 | 주황 | 7 | 1,500–4,000 |
| 신화 | 분홍(빛남) | 1.5 | 8,000–20,000 |

종 수는 지역당 12–14종, 총 75종입니다. 목록은 `shared/data/fish.js`에 있습니다.

### 개체 크기 → 품질 등급
- 종마다 최소/최대 무게가 있고, 개체마다 백분위 `p`(0–1)를 굴려 로그 보간으로 무게를 정합니다 (`p = rand^1.8`이라 작은 개체가 흔함)
- 미끼·버프의 크기 보너스는 `p`의 분포를 위쪽으로 밀어 줍니다
- 품질 등급은 `p`로 정합니다

| 등급 | p 범위 | 가격 배수 | 대략적 확률 |
|---|---|---|---|
| 소형 | < 0.40 | ×0.8 | 60% |
| 보통 | < 0.72 | ×1.0 | 23% |
| 대형 | < 0.90 | ×1.4 | 11% |
| 대물 | < 0.98 | ×2.2 | 4.6% |
| 괴물급 | ≥ 0.98 | ×4.0 | 1.1% |

- 큰 개체일수록 미니게임에서 더 세게 저항합니다
- 종마다 서버 최대어 기록이 있고, 갱신하면 전체에 알림이 갑니다

### 특수 변이 (9종, 모든 종에 붙을 수 있음)
기본 변이 확률은 2.5%이고, 미끼·버프·조건에 따라 오릅니다.

| 변이 | 외형 | 가치 | 잘 나오는 조건 | 파티 버프 (반경 45m, 성운은 서버 전체) |
|---|---|---|---|---|
| 이끼 | 초록 이끼로 덮임 | ×1.8 | 늪, 비 | **풍성한 채집**: 채집량 +1 (3분) |
| 달빛 | 푸른 은빛 발광, 반짝임 | ×2.5 | 밤 | **달의 가호**: 희귀 이상 확률 +20% (3분) |
| 잿불 | 숯빛 몸에 주황 균열, 불씨 | ×2.5 | 온천 | **불꽃 의지**: 줄 최대 텐션 +20% (3분) |
| 그림자 | 칠흑 실루엣, 연기 | ×3 | 안개 | **고요한 물**: 입질 대기 −25% (3분) |
| 유령 | 반투명, 깜빡임 | ×3.5 | 밤 + 안개 | 없음 |
| 뇌전 | 번쩍이는 노란 전류 | ×4 | 폭풍 | **전율**: 입질 대기 −35% (2분) |
| 수정 | 투명하고 반짝이는 결정 | ×5 | 맑음 | **맑은 물결**: 크기 보너스 +0.3 (3분) |
| 청자 | 비취색 도자기와 빙열 무늬 | ×6 | 낮 | **장인의 손길**: 판매가 +20% (3분) |
| 성운 | 움직이는 별무리 우주 무늬 | ×12 | 매우 희귀 | **별의 축복**: 변이 확률 ×2 (5분, **서버 전체**) |

## 5. 낚시 진행

1. **캐스팅**: 물가에서 마우스 왼쪽을 누르고 있으면 파워가 차고, 놓으면 던짐 (최대 거리는 낚싯대에 따라 다름)
2. **대기**: 찌가 물에 뜸. 가짜 입질(살짝 흔들림)이 섞여 나옴
3. **입질**: 찌가 쑥 들어가고 머리 위에 느낌표 말풍선이 뜸 → 반응 시간 안에 클릭해서 챔질 (일반 0.85초, 희귀할수록 짧아져 최소 0.35초). 이때 미끼가 소모됨
4. **추적 바 미니게임** (스타듀밸리식, `shared/minigame.js`): 세로 게이지 안에서 물고기가 위아래로 움직이고, 플레이어는 누르면 올라가고 떼면 떨어지는 초록 찌 구간으로 물고기를 덮어야 함. 덮는 동안 진행도가 오르고, 놓치면 내려감. 30%에서 시작해서 100%면 성공, 0%면 도망감
   - 난이도 d = 0.1 + 희귀도×0.15 + 크기 백분위×0.2 (최대 1). d가 높을수록 물고기가 빠르고 자주 방향을 바꿈
   - 움직임 유형은 몸 모양으로 정해짐: 변덕(무작위), 돌진(먼 거리를 순간 이동), 바닥(아래 선호), 수면(위 선호), 유영(사인파)
   - 낚싯대 텐션 → 찌 구간 폭 (대나무 20% ~ 성운 40%), 감기 속도 → 진행도 상승 속도
   - 시뮬레이션 기준 승률 (보통 실력): 대나무로 일반 83%, 희귀 30%, 전설 3% / 용골로 희귀 100%, 전설 65%, 신화 43%
5. **획득**: 종, 무게, 품질, 변이가 공개됨. 다른 플레이어에게도 물고기를 들어 올리는 모습이 보임

서버가 판정을 맡습니다: 물고기 추첨, 캐스팅 위치·거리 검증, 챔질 타이밍 검증, 미니게임 최소 소요 시간 검증.

## 6. 미끼와 제작

- 미끼마다 **태그**(지렁이, 곤충, 새우 등)가 있고, 물고기는 좋아하는 태그가 정해져 있음 (좋아하는 미끼면 출현 가중치 ×3)
- 미끼 효과: 입질 속도, 희귀도 보너스, 크기 보너스, 변이 확률 배수
- 미끼 없이 맨바늘로도 낚시할 수 있음 (느리고, 고급 이하만 나옴)

### 재료 획득
| 출처 | 재료 |
|---|---|
| 채집 (E키, 노드마다 재생성 60–150초, 먼저 캐는 사람이 가져감) | 지렁이, 굼벵이, 귀뚜라미, 산딸기, 조개, 새우, 해초, 버섯, 반딧불이(밤에만), 이끼, 유황 |
| 손질 (물고기 분해) | 생선살, 비늘, 내장, 빛나는 비늘(희귀 이상), 변이 정수(변이 물고기) |
| 상점 | 밀가루, 옥수수, 빵가루, 지렁이·새우(비쌈) |
| 거래 | 플레이어끼리 재료, 미끼, 물고기, 돈을 교환 (양쪽 준비 → 양쪽 확정, 서버가 한 번에 처리) |

미끼 레시피 16종과 제작 낚싯대 1종은 `shared/data/items.js`에 있습니다. 제작은 C키로 어디서든 할 수 있고, 캠프의 제작대에서 E키로도 열립니다. 상점 판매·구매는 캠프의 상점 주인 근처에서만 됩니다.

## 8. 멀티플레이 요소
- 공유 월드: 다른 플레이어의 이동, 캐스팅, 찌, 파이팅, 물고기 들어 올리기가 보임
- 채팅, 시스템 알림 (전설 이상, 변이, 종별 신기록)
- 파티 버프: 변이 물고기를 잡으면 주변 사람 모두가 버프를 받음
- 채집 노드 경쟁
- 플레이어 간 거래
- 랭킹: 최고 가치 어획, 총 수입, 도감 수집 수, 종별 최대어 기록

## 10. 기술 구조
```
shared/   지형 함수(서버·클라 공용, 시드 고정), 지역 판정, 게임 데이터(물고기/미끼/레시피/낚싯대/변이)
server/   ws 서버, 플레이어·월드 상태, 낚시 판정, 채집, 제작, 상점, 거래, JSON 저장
client/   Three.js 렌더링(지형/물 셰이더/하늘/날씨/캐릭터/절차적 물고기 모델), HTML UI
```
- 서버 10Hz로 스냅샷 브로드캐스트, 이동은 클라이언트가 보고하고 서버가 범위만 검증
- 저장: `data/db.json` 원자적 저장 (5초 디바운스 + 종료 시)

## 11. 2차 업데이트 (플레이 피드백 반영)

### 수익 재조정
- 입질 대기는 원래대로 5~16초 유지 (빠르게 했다가 손맛이 줄어 되돌림), 지역별 판매가 배수(호수·강·해안 ×2, 늪 ×2.5, 심해·온천 ×3)
- 낚싯대 가격: 유리섬유 2,000 / 카본 8,000 / 티타늄 25,000 / 용골 80,000
- 시뮬레이션(쉬지 않는 보통 실력 봇, 요리 수익 제외) 기준 용골까지 약 3시간 → 요리 수익 포함 실제 플레이 3~4시간 목표

### 낚시 레벨 (`shared/level.js`)
- 잡을 때마다 경험치(희귀도·품질·변이에 비례, 놓치면 1), 레벨 1~30
- 레벨당 찌 구간 +0.5%p, 물고기 속도 -0.7%, 챔질 여유 +0.01초, 감기 +1%

### 파이팅 도구 (1~4 키, 종류당 한 번)
| 도구 | 효과 | 얻는 법 |
|---|---|---|
| 뜰채 | 진행도 +25% | 상점 120 / 해초4+비늘3 |
| 진정 떡밥 | 5초간 물고기 -40% 속도 | 상점 90 / 떡밥2+이끼1 |
| 큰 찌 | 6초간 찌 구간 ×1.3 | 상점 100 / 빛나는 비늘1+비늘2 |
| 질긴 낚싯줄 | 진행도 감소 절반 | 상점 140 / 해초3+내장2 |

### 모바일
- 가로 화면 전용(세로면 안내), 왼쪽 조이스틱·오른쪽 시점·두 손가락 줌, 행동 버튼(던지기/챔질/감기/회수), E·점프·채팅·전체화면 버튼
- 모바일은 해상도 1.25배 제한, 그림자 1024, 풀 1/3

### 요리 (`shared/data/cooking.ts`, `server/cooking.ts`, `client/src/ui/components/panels/Cook.tsx`, `client/src/ui/cookgame.ts`)
- **조리대**: G 키로 내 앞에 깔고 다시 누르면 거둠. 가진 조리 도구가 모두 올라가고 다른 플레이어에게 보임
- **조리 도구**: 석쇠(기본 지급), 도마 300, 냄비 800, 튀김솥 1,500. 2·3단계로 올리면 미니게임 판정 ×1.25 / ×1.5
- **조리**: 재료 최대 5칸(물고기·식재료·채집물) → 도구별 2단계 미니게임
  - 도마: 칼질 타이밍 4번 + 담기 / 석쇠: 앞면·뒷면 뒤집기 타이밍 / 냄비: 불 조절(구간 유지) + 간 맞추기 / 튀김솥: 기름 온도 유지 + 건지기
- **레시피 35종**: 젤다식 태그 조합. 맞으면 발견되어 요리 도감에 기록, 상점에서 레시피를 살 수도 있음. 숨은 요리 6종(전설·신화 물고기)
- **요리 품질**: 별 = 미니게임 점수 75% + 물고기 품질 25%. 별 → 버프 세기, 재료량(물고기 무게 등) → 지속 시간(2~20분)
- **버프 종류**: 찌 구간, 물고기 둔화, 입질 속도, 희귀 확률, 큰 개체, 변이 확률, 경험치, 판매가, 감기 속도. 음식 버프는 하나만 적용
- **판매**: 상점에 팔면 재료 원가의 약 2~2.8배. 조리대 진열대(6칸)에 가격을 정해 올리면 다른 플레이어가 사 감(조리대가 깔려 있고 접속 중일 때). 1:1 거래에도 요리를 올릴 수 있음
