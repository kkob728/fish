# 🎣 물비늘 섬

브라우저에서 바로 접속하는 **멀티플레이 3D 로우폴리 낚시 게임**입니다. 모두가 같은 섬에서 함께 낚시합니다.

- 6개 지역에 **77종**의 물고기가 있고, 희귀도는 6단계(일반 → 신화)입니다
- 같은 종이라도 개체마다 **무게와 크기**가 다르고, 크기에 따라 **품질 등급**(소형 → 괴물급)이 매겨집니다
- 어떤 종에든 붙을 수 있는 **특수 변이** 9종이 있습니다. 변이마다 고유 이펙트와 가치 배수가 있고, 잡으면 주변 플레이어에게 **파티 버프**를 줍니다
- 재료(채집, 물고기 손질, 상점, 거래)로 만드는 **미끼 16종**과 제작 전용 낚싯대가 있습니다
- 낮과 밤, 날씨(맑음/흐림/비/안개/폭풍)에 따라 나오는 물고기와 변이가 달라집니다
- 실시간 이동, 채팅, 플레이어 간 거래, 랭킹, 종별 서버 최대어 기록을 지원합니다
- 외부 에셋은 쓰지 않습니다. 지형, 캐릭터, 물고기, 효과음까지 전부 코드로 만듭니다

기획서는 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
```

### 개발 모드
서버(3000)와 Vite(5173)를 함께 띄웁니다. 브라우저에서 http://localhost:5173 으로 접속하세요.

```bash
npm run dev
```

### 배포 모드
클라이언트를 빌드한 뒤, 서버 하나가 정적 파일과 WebSocket을 모두 처리합니다. http://localhost:3000 으로 접속하세요.

```bash
npm run build
```

```bash
npm start
```

환경 변수:
- `PORT`: 서버 포트 (기본 3000)
- `DATABASE_URL`: Postgres 접속 주소. 있으면 진행 상황을 DB에 저장합니다 (`fish_store` 테이블이 자동으로 생깁니다)
- `DATA_DIR`: `DATABASE_URL`이 없을 때 쓰는 저장 폴더 (기본 `./data`, 안에 `db.json`이 생깁니다)

### Render 배포 (무료) + Neon (무료 Postgres)
Render 무료 플랜은 디스크가 자주 초기화되기 때문에, 진행 상황은 Neon에 저장합니다.

1. [Neon](https://neon.tech)에서 프로젝트를 만들고(지역은 Singapore 추천) **Connection string**(`postgresql://...`)을 복사합니다
2. [Render](https://render.com)에 GitHub 계정으로 로그인한 뒤 **New → Blueprint**에서 이 저장소를 고릅니다. `render.yaml` 설정이 자동으로 적용됩니다
3. `DATABASE_URL` 입력 칸에 1번에서 복사한 주소를 붙여 넣고 **Apply**를 누릅니다
4. 빌드가 끝나면 `https://mulbineul-island-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 친구들에게 공유하면 됩니다

무료 플랜이라 15분 동안 아무도 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 50초쯤 걸립니다. 진행 상황은 DB에 남아 있습니다. `main` 브랜치에 푸시하면 자동으로 다시 배포됩니다.

### 점검 스크립트
- `npm run check`: 데이터 무결성 검사와 낚시 확률 시뮬레이션
- `node scripts/bot.js 3000`: 실행 중인 서버에 봇으로 접속해서 캐스팅부터 판매까지 한 바퀴 돌려 봅니다

## 구조
모든 코드는 TypeScript입니다. 서버는 Node 24가 .ts를 바로 실행하고, 클라이언트는 Vite가 묶습니다.
```
shared/            서버와 클라이언트가 함께 쓰는 코드
  types.ts         공용 타입 (물고기 기록, 아이템, 요리, 프로필…)
  world.ts         시드 고정 지형 높이 함수, 지역 판정, 부두, 채집 노드, 장식 배치
  fishing.ts       출현표, 변이, 크기·품질, 가격, 손질 결과
  minigame.ts      스타듀식 추적 바 미니게임 (클라이언트가 돌리고 서버가 최소 시간 검증)
  level.ts         낚시 레벨과 레벨 보너스
  data/            물고기 77종, 미끼·재료·레시피, 요리, 희귀도·변이·낚싯대·시간·날씨
server/            Node + ws (서버가 판정을 맡음)
  game.ts          접속·메시지 분배·스냅샷(10Hz)
  core.ts          세션, 방송, 버프, 경험치 같은 공용 도구
  fishing.ts / gather.ts / shop.ts / social.ts / cooking.ts / trade.ts   기능별 처리
  db.ts            저장 (DATABASE_URL이 있으면 Postgres, 없으면 data/db.json)
client/src/        Three.js + Preact UI
  scene/           지형, 물 셰이더, 하늘·날씨, 소품, 캐릭터, 절차적 물고기 모델, 파티클, 조리대
  game/            내 캐릭터·카메라, 낚시 상태 머신과 추적 바 UI, 다른 플레이어, 터치 조작
  ui/store.tsx     UI 상태 저장소 (toast, openPanel 같은 함수를 게임 코드가 부름)
  ui/events.tsx    화면을 바꾸는 서버 이벤트 모음
  ui/components/   HUD, 패널(가방/제작/상점/도감/랭킹/거래/조리대), 카드 — Preact 컴포넌트
  ui/cookgame.ts   요리 미니게임
test/              node:test 자동 테스트 (npm test)
```

## 치트 방지
- 물고기 추첨, 무게, 변이는 모두 서버에서 정합니다
- 캐스팅 거리와 물 여부, 낚싯대 등급, 챔질 타이밍, 미니게임 최소 소요 시간, 채집 거리, 상점 근접 여부를 서버가 검증합니다
- 이동은 클라이언트가 보고하지만, 비정상적으로 먼 순간이동은 되돌립니다
- 닉네임은 처음 만든 브라우저에 저장된 토큰으로만 다시 로그인할 수 있습니다
